# Operating Workflow

## Standard Book Flow

1.  Create the book brief.
2.  Select/create reusable characters.
3.  Generate scene concepts.
4.  Approve scene concepts.
5.  Produce/import coloring artwork.
6.  Review artwork for age suitability and character consistency.
7.  Mark only approved artwork as layout-ready.
8.  Apply page layout.
9.  Build interior PDF.
10. Run automated preflight/QC.
11. Build cover after final publishing parameters are known.
12. Prepare metadata and economics.
13. Export a release package.
14. Preserve source material and build records.

## First Book Art Standard

The first book is for very young children: - thick outlines - large
blank/open regions - simple forms - low visual density - obvious
action - friendly cozy scenes - consistent recurring animals

## Diagnostic/Engineering Style

Use the same disciplined loop throughout development:

**specification → measurement → comparison → verification →
documentation**

Do not claim a slice works because code was written. Demonstrate the
result with a test, generated artifact, or explicit check.
