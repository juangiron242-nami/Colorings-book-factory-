# Slice 00 --- Inventory and Recovery

## Outcome

Know exactly what already exists before changing architecture.

## Tasks

-   List all files and directories.
-   Identify source code and runtime entry points.
-   Locate the existing four-page prototype if present.
-   Locate character/source images if present.
-   Locate generated PDFs and covers if present.
-   Locate book/config/metadata files.
-   Identify duplicates and abandoned experiments.
-   Identify dependencies and how the current project runs.
-   Record anything that cannot be understood without additional
    context.

## Deliverable

Create `PROJECT_INVENTORY.md` with: - current tree - what works - what
is incomplete - valuable assets to preserve - missing items -
recommended next slice

## Stop Condition

Do not reorganize or delete files in this slice.
