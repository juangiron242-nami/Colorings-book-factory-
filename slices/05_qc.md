# Slice 05 --- Automated Preflight

## Outcome

A build can fail clearly when publishing inputs are wrong.

## Checks

Where technically possible: - missing artwork - unapproved artwork -
wrong page dimensions - bad page order/count - insufficient raster
resolution - safe-area violations - missing required configuration -
missing metadata - stale/mismatched build artifacts

## Deliverable

Human-readable QC report plus machine-readable pass/fail.
