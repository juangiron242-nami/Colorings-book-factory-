# Cursor Handoff Instructions

You are taking over an existing project called **Coloring Book
Factory**.

## First Action

Do not immediately rewrite the repository.

1.  Inventory every existing file.
2.  Identify working code, prototypes, artwork, PDFs, configs, and
    duplicate/legacy material.
3.  Compare the existing repository to `PRODUCT_PRD.md` and
    `ARCHITECTURE.md`.
4.  Produce a short gap report.
5.  Begin with `slices/00_inventory.md`.

## Agent Behavior

-   Work one vertical slice at a time.
-   Explain what file(s) will change before making broad changes.
-   Preserve existing assets.
-   Do not fabricate missing character details, KDP dimensions,
    publishing settings, or project history.
-   If an existing implementation already satisfies a requirement, keep
    it and document it.
-   Prefer small commits with meaningful messages.
-   Keep generated outputs out of source directories.
-   Make the project understandable to the next engineer without chat
    history.

## Goal

Turn the existing material into a reliable reusable factory, not merely
a folder containing one PDF.
